- Theme Studio: create, edit, rename, duplicate and delete your own themes with a live
  preview drawn by the same renderer the keyboard uses.
- Twelve anime-inspired preset palettes, with contrast checked so labels stay readable.
- Theme files are validated on import: a theme cannot reference a remote URL or a file
  outside the app, and a malformed file is rejected with a message instead of a crash.
- The app now checks this repository's releases for a newer version, once, with the
  release notes and a link. Checks are cached and never block typing.
