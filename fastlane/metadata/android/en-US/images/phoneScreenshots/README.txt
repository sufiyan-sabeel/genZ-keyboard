Real screenshots of the running app go here, named 1.png, 2.png, ... (PNG or JPEG).

The two screenshots that used to be in this directory were removed: they were captured from
build 1.0.0/1.0.1 and still showed the old "In version 11.2.0" label and the pre-anime settings
UI, which would misrepresent the current release.

To refresh them: install the latest release, then capture at least four screens:

1. Settings -> Themes -> Anime themes (the gallery with artwork cards)
2. The keyboard itself, open in any text field, with one anime theme applied
3. Settings home (dark mode switch, sections)
4. The emoji panel or the theme preview dialog

F-Droid shows these on the listing; without at least one graphic the app is not shown on the
"Latest" tab, which is why featureGraphic.png is present as a fallback.
